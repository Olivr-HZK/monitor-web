# 监测汇总网站 — 导航与功能（给 AI 助手）

本文档以**当前前端代码**为准，用于回答「网站怎么用」「入口在哪」类问题。

## 顶部导航（5 个入口）

| 标签 | 路由/行为 | 说明 |
|------|-----------|------|
| 监测汇总 | `/` | 首页看板，展示四类监测统计与快捷入口卡片 |
| AI热点 | `/type/ai热点监测` | AI 热点监测列表与详情 |
| 趋势监测 | `/type/热点趋势监测` | 热点趋势监测列表与详情 |
| 休闲游戏监测 | `/type/休闲游戏监测` | 休闲游戏：周报、榜单、SensorTower、竞品等 |
| AI产品监测 | `/type/AI产品监测` | AI 产品：产品周报、UA 素材、新产品速览等 |

## 主要子路由（给 AI 内部用；回答用户时见下文「用户面向说明」）

- 休闲游戏 — 微信/抖音排行榜：`/rankings/casual/wechat_douyin`
- 休闲游戏 — SensorTower 榜单页：`/rankings/casual/sensortower`
- AI 产品素材库（新/热/飙升三榜）：`/rankings/ai`
- 报告详情：`/report/:id`（`:id` 为监测条目 id）
- 商店页卡片详情（SensorTower 新进榜等）：`/store/:id`
- 玩法解析：`/gameplay/:source/:gameName`（`gameName` URL 编码）

## 用户面向说明（重要）

- **`/xxx` 不是「接口名」或后端 API**，而是本站前端页面的**站内路径**（单页应用里的路由）。对用户不要说「接口」「调用某某 API」，应说「页面」「入口」「榜单页」。
- **不要**把 `:id`、`:source`、`:gameName` 这种**路由占位符**原样展示给用户；应说明**怎么操作**：例如「在休闲游戏排行榜里点击游戏名」或「打开某游戏玩法解析」。
- 需要给出可跳转指引时，优先用 **Markdown 链接**，链接文字写功能名，地址用站内路径，例如：
  - `[微信/抖音小游戏排行榜](/rankings/casual/wechat_douyin)`
  - `[SensorTower 休闲游戏榜](/rankings/casual/sensortower)`
  - 用户侧会渲染为可点击链接，**不会**看到「接口」或组件名。
- 玩法解析：说明「从榜单进入」或「某游戏」即可；若需直达，可写 `[玩法解析](/gameplay/wechat_douyin/游戏名)`（`游戏名` 需 URL 编码，与排行榜页里点击游戏名跳转一致）。

## 休闲游戏监测 — 侧栏结构（代码侧）

- **微信 / 抖音小游戏**：子类含「周报简要」等（数据主要来自 `wechatdouyin.db` 与 CSV 回退）。
- **SensorTower 榜单**：子类含「周报简要」「商店页变化」等（数据来自 `sensortower_top100.db`）。
- **竞品监测**：社媒监控、UA 素材；社媒周报可来自 `competitor_data.db` 的 `weekly_reports`。

休闲游戏首页还提供三张快捷卡片：进入微信/抖音排行榜、SensorTower 排行榜、打开竞品监测。

## AI 产品监测 — 侧栏子类

- 新产品速览

列表页「进入素材库」按钮跳转到 `/rankings/ai`（`ai_products_ua.db` 三榜）。

## 全局 AI 对话

- 右下角「AI 对话」浮层，调用后端 `/api/ai/chat` 与 `/api/ai/chat/stream`。
- 生产环境若配置要求登录，需先登录后再用。

### 对用户说明数据与边界（重要）

- 用户**不能**直接访问数据库、不能执行 SQL、不能下载 `.db` 等原始数据文件；监测数据**仅通过网站页面**（列表、详情、排行榜、表格等）展示。
- 若知识库中写了「数据来自 `xxx.db`」等，仅供你内部理解来源；向用户解释时改为「在某某页面可以看到……」。
- 助手在服务端可能使用只读查询等工具核对事实，这是**后台能力**，**不是**用户侧功能；不要写成「你可以查库」。

## 功能真值（避免向用户承诺未实现能力）

| 能力 | 状态 |
|------|------|
| 列表内时间范围、分类、排序、按平台筛选（因页面而异） | **多数已实现**（见 MonitorList） |
| 商店页变化 — 按日期 + 游戏名搜索 | **已实现** |
| SensorTower / 素材库页内搜索与导出 | **已实现**（各表格组件内） |
| 顶部导航栏「搜索监测内容」输入框 | **多为 UI 占位**，未接全站搜索逻辑 |
| 顶部「深色模式」按钮 | **多为本地状态**，未全局切换主题 |
| 顶部「通知」图标 | **占位** |
| 列表「高级筛选」内情感/趋势下拉 | **UI 存在**，选项**未接入**实际过滤逻辑 |

回答用户时：若问「为什么搜不到」，应说明顶部搜索可能未接全站检索，建议在具体列表页或排行榜页使用页内搜索/筛选。
