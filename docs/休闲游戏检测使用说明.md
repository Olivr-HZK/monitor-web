# 休闲游戏监测 - 使用说明（面向非技术同事）

本文分为两部分：

1. **完整使用流程**：从企业微信收到推送开始，一步步说明如何在网站上看周报、排行榜，以及如何继续跳转到商店页或 SensorTower 链接。  
2. **数据来源与逻辑**：说明各块内容（榜单、周报、商店页变化、竞品社媒等）背后的**数据来源**和**展示逻辑**，帮助理解「这些东西是怎么算出来的」。

---

## 一、完整使用流程（从企业微信到商店页 / SensorTower）

本章只讲「怎么用」，不讲技术细节。可以按下面几个典型场景来理解。

### 1. 从企业微信游戏周报，看到完整周报与榜单

1. **在企业微信里**  
   - 每周一早上，群里会收到一条或多条「游戏监测周报」消息（SensorTower 周报），里面分为：  
     - 一、本周新进 Top50  
     - 二、本周排名飙升 Top10  
     - 三、商店页的更新  
   - 消息底部会有「查看当周完整周报」或「监测汇总平台」的链接。
2. **点击链接，打开网站**  
   - 浏览器会打开监测汇总网站；如配置了访问密码/账号，先完成登录。  
3. **在网站上找到这一期周报**  
   - 右侧「监测源」中选择 **SensorTower**，分类选 **周报简要**。  
   - 中间列表里会按日期列出各期「SensorTower 周报（YYYY-MM-DD）」；找到和企微消息同一天的那一条，点开进入详情。  
4. **查看周报详情**  
   - 在详情页可以看到完整的「新进 Top50」「排名飙升 Top10」表格，以及「商店页更新」的列表，每条都有名称、国家/地区、平台、下载量/收入等。  
5. **跳到具体游戏商店页或 SensorTower 页面**  
   - 在周报表格中，游戏名通常是**可点击的链接**：  
     - 点游戏名（或「商店链接」） → 打开 App Store / Google Play 商店页。  
     - 若周报中有带 `📊 SensorTower` 的链接，点它 → 打开对应的 SensorTower 概览页（需有访问权限）。  

> 小结：**企微只给你「摘要 + 入口」**，真正细看的时候，一定要在网站里打开对应那期周报，表格才是完整的。

### 2. 在网站上看微信 / 抖音小游戏排行榜与周报

1. **进入休闲游戏监测**  
   - 打开监测汇总网站后，在顶部导航点击 **「休闲游戏监测」**，或直接访问休闲游戏子站。  
2. **看排行榜（Top20）**  
   - 在首页点击「微信/抖音小游戏」卡片，或右侧选择 **微信/抖音** → 进入排行榜页。  
   - 如有「按周」选择，选择某一周，可以看到该周的**微信小游戏 Top20**、**抖音小游戏 Top20**表格。  
   - 表格里包含排名、游戏名、开发公司、分类、排名变化（上升/下降/新进榜）等；从这里可以快速看到当周的头部游戏。  
3. **看「新游戏」与「新玩法」列表**  
   - 在右侧「监测源」里选择：  
     - 分类选 **新游戏**：只看本周新进榜的游戏；  
     - 分类选 **新玩法**：只看本周排名飙升较大的游戏。  
   - 列表里的每一张卡片代表一款游戏，点击可进入**玩法拆解**详情（若有），查看这款游戏的核心玩法、操作方式、基线对标、创新点等。  

> 小结：**排行榜**适合看「谁在前面」；**新游戏/新玩法列表**适合看「本周新增值得拆解的游戏」。

### 3. 在网站上看商店页更新（截图/图标/视频等）

1. 在右侧「监测源」中选择 **SensorTower**，分类选 **商店页变化**。  
2. 中间会出现一组「商店页变化」卡片，每张卡片对应一个应用/游戏，标题类似「某某（截图、图标变化）」。  
3. 点击卡片，进入**商店页变化详情**：  
   - 会明确标出本次变更的时间、平台（iOS/Android）、开发者、商店链接，以及「具体变更项」列表，例如：  
     - 截图已更新  
     - 图标已更新  
     - 下载量：100万+ → 200万+  
4. 若有「商店链接」，点击即可跳转到 App Store / Google Play 上的该游戏页面，方便直接看最新素材和文案。

### 4. 在网站上看竞品社媒动态（社媒更新）

1. 在右侧「监测源」选择 **竞品 → 社媒更新**。  
2. 中间会列出各家公司的**社媒周报卡片**，例如「📊 A 公司 周报 (02-03 ~ 02-09)」。  
3. 若只关心某一家公司，可以在侧栏的「公司」下拉框中选定该公司，列表即只保留这家公司的条目。  
4. 点击某张卡片进入**周报详情**：  
   - 里面按平台整理了该公司在一周内的社媒动态，包含文案/活动/玩法更新等；  
   - 页面上会显示一个**可用性评分**（平均分），帮助快速判断本周内容质量与落地程度。  
5. 通常不会从这里再跳转到外部链接，而是直接在周报详情里看完关键信息（必要时可回到原始渠道自行搜索）。

### 5. 在网站上看竞品 UA 素材日报

1. 在右侧「监测源」选择 **竞品 → UA 素材**。  
2. 中间是 UA 素材日报卡片列表，每条都是一篇素材分析（目前来源主要是广大大等）。  
3. 点击卡片进入详情，即可查看这一期 UA 素材的：投放平台、素材形式、估算效果、适合借鉴的切入点等内容。  

### 6. 登录与访问方式（流程视角）
