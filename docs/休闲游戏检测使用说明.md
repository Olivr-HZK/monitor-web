# 休闲游戏检测 - 使用说明

本文档说明**休闲游戏检测**的登录方式、各模块内容及具体使用方法，并包含企业微信端接收周报/日报的说明。

---

## 一、概述与入口

**休闲游戏检测**是监测汇总平台中专注于休闲游戏方向的子模块，用于集中查看：

- 微信 / 抖音小游戏排行榜与周报
- SensorTower 全球榜单（iOS/Android Top100、排名异动、商店页变化）
- 竞品动态（社媒更新、UA 素材等）

### 访问方式

- **独立入口（仅休闲游戏）**：若部署了独立页面，可直接打开对应地址（如 `casual.html` 或构建后的 `/casual.html`），只显示休闲游戏相关功能，无其他监测类型。
- **主站入口**：在监测汇总主站顶部导航点击「休闲游戏检测」，进入休闲游戏视图。

---

## 二、登录方式

休闲游戏检测与主站共用同一套鉴权，根据部署方式不同，登录方式分为以下几种。

### 2.1 静态站 + 访问密码（无后端）

当站点以纯静态方式部署（如 GitHub Pages）且配置了访问密码时：

1. 打开页面后先看到**登录框**，只需输入**访问密码**（无需用户名）。
2. 输入正确密码后点击「进入」，即可看到全部内容。
3. 同一浏览器标签页内会保持已解锁状态；**关闭标签页后再次访问需重新输入密码**。

**说明**：密码在浏览器内与哈希比对，不经过服务器，适合「不想被随便看到、但不涉及敏感数据」的轻量保护。

### 2.2 带后端的用户名 + 密码登录

当站点配置了登录后端（如自建 `server`）时：

1. 打开页面后若未登录，会跳转到登录页。
2. 输入**用户名**和**密码**，点击「登录」。
3. 登录成功后，右上角会显示当前用户名和「退出」按钮；点击「退出」可登出。

后端账号与密码由管理员在 `server/.env` 中配置（如 `LOGIN_USERNAME`、`LOGIN_PASSWORD_HASH`），具体见 [登录与后端部署](./登录与后端部署.md)。

### 2.3 未配置密码或未启用后端

若未配置访问密码且未启用后端，打开页面会直接进入内容，无需登录。

## 三、企业微信端与周报/日报推送

**企业微信端**不提供「在企微里登录网站」的功能，而是通过**企业微信机器人**把周报/日报推送到指定群或会话，便于在手机或电脑上快速查看摘要，并可通过链接跳转到网站查看完整内容。

### 3.1 推送内容类型

| 类型           | 说明                     | 典型发送时间   |
|----------------|--------------------------|----------------|
| 热点日报       | 当日热点趋势摘要与列表   | 每日 10:30     |
| AI 日报        | 当日 AI 热点话题摘要     | 每日 10:30     |
| 游戏检测周报   | SensorTower 周报摘要     | 每周一 10:30   |

### 3.2 游戏检测周报（企业微信）包含什么

推送至企业微信的**游戏检测周报**为 Markdown 消息，单条有 4096 字节上限，内容来自 `send_minigame_weekly_reports.py`，一般包括：

1. **一、SensorTower 本周新进 Top50**  
   本周新进榜单且排名在 Top50 内的游戏列表（已合并同款多地区），含游戏名、本周排名、商店链接、SensorTower 概览链接等。

2. **二、SensorTower 本周排名飙升 Top10**  
   本周排名飙升最明显的 10 款游戏，含游戏名、排名变化、商店链接等。

3. **三、商店页的更新**  
   本周期内商店页有更新的应用/游戏列表，含名称与商店链接。

文末会附带「查看当周完整周报」的链接，点击可跳转到监测汇总平台对应周报页面。

若周报较长，企业微信会拆成多条发送（例如第一条为一+二节，第二条为三节+底部），避免单条超长被截断。

### 3.3 如何配置企业微信推送

1. 在企业微信群或会话中添加「自定义机器人」，获取 Webhook 地址。
2. 在项目根目录 `.env` 中配置：
   - `WECOM_WEBHOOK_URL_REAL` 或 `WECOM_WEBHOOK_URL`：企业微信机器人 Webhook。
3. 定时任务示例（游戏周报每周一 10:30）：
   ```bash
   # 游戏检测周报（仅发送 game）
   ./scripts/run_reports.sh --content game
   ```
   实际 cron 配置可参考 [自动任务与推送](./自动任务与推送.md)。

## 四、页面布局与模块说明

休闲游戏检测页面主要分为：

- **顶部**：标题「休闲游戏检测」、当前用户与退出（若已登录）。
- **主区域（左侧）**：首页为三个快捷卡片 + 监测列表；也可进入排行榜、报告详情、商店页详情。
- **右侧边栏「监测源」**：选择数据大类与子类，决定主区域列表展示哪些内容。

## 五、各模块内容与使用方式

### 5.1 首页三个快捷入口

在休闲游戏首页上方有三个卡片，用于快速跳转：

| 入口                   | 作用 |
|------------------------|------|
| **微信/抖音小游戏**    | 跳转到「微信/抖音小游戏」排行榜页，查看微信与抖音小游戏榜单。 |
| **SensorTower 榜单**   | 跳转到 SensorTower 排行榜页，查看 iOS Top100、Android Top100 及榜单异动。 |
| **竞品监测**           | 不跳转新页面，而是将右侧监测源切换为「竞品 → 社媒更新」，主区域显示竞品社媒相关内容。 |

### 5.2 右侧「监测源」侧栏

右侧栏仅展示「休闲游戏监测」相关选项，分为两块数据源与多个分类。

#### 数据块切换：微信/抖音 与 SensorTower

- **微信 / 抖音小游戏**：数据来自微信、抖音小游戏周报与榜单。
- **SensorTower**：数据来自 SensorTower 数据库（如 `sensortower_top100.db`），包括 iOS/Android 榜单、排名变化、商店页变化等。

切换上述两块后，主区域列表只会显示对应来源的监测项。

#### 分类（在选定数据块下）

| 分类         | 说明与使用方式 |
|--------------|----------------|
| **周报简要** | 按周期整理的完整周报摘要。选「微信/抖音」时显示微信/抖音小游戏周报；选「SensorTower」时显示 SensorTower 周报。点击卡片可进入该周报详情页。 |
| **商店页变化** | 仅 SensorTower 数据块下出现。展示本周期内商店页有更新的应用/游戏，点击可进入商店页详情（若有）。 |
| **新游戏**   | 各平台新游戏周报或上榜新游戏。可选**平台**：微信、抖音、iOS、安卓。主区域会显示对应平台的「新游戏」类条目，并可点击「进入排行榜」查看该平台排行榜。 |
| **新玩法**   | 与「新玩法」相关的监测内容（如新玩法拆解、案例）。 |
| **玩法拆解** | 汇总视图，同时包含新游戏 + 新玩法类内容；在 SensorTower 数据块下还会包含商店页变化卡片（若有）。 |
| **竞品**     | 竞品动态，下分两个子类：**社媒更新**（竞品社媒周报，可按公司筛选）、**UA 素材**（竞品 UA 素材相关）。选择「社媒更新」后，侧栏会列出「全部公司」及各公司名，选择某公司可只显示该公司周报。 |

**使用方式小结**：先在右侧选择「微信/抖音」或「SensorTower」，再选择上述某一分类（及必要时选择平台或公司），主区域即显示对应列表；点击卡片可进详情或商店页，在「新游戏」下还可点「进入排行榜」看榜单。

### 5.3 主区域列表与筛选

- 列表以**卡片**形式展示每条监测（标题、来源、日期、平台、描述等）。
- 有完整内容的条目（如周报、日报）**整张卡片可点击**，进入详情页阅读全文。
- 部分条目（如商店页变化）点击后会进入商店页详情而非通用报告详情。
- 列表上方可有时间范围、分类、排序等筛选（若页面提供），便于缩小查看范围。

### 5.4 排行榜页面

- **入口**：在「新游戏」分类下，主区域上方有 **「微信/抖音排行榜」** 或 **「进入排行榜」** 按钮；或通过首页「微信/抖音小游戏」「SensorTower 榜单」两个卡片进入。
- **微信/抖音排行榜**：顶部为平台标签（如微信小游戏、抖音小游戏），可切换；表格列为排名、游戏名称、开发商、分类、排名变化、更新时间等，排名变化会用颜色或箭头区分。
- **SensorTower 排行榜**：可切换 iOS/Android 等，展示 Top100 及异动（新进榜、排名飙升等）。
- 左上角**「返回」**可回到进入前的列表或首页。

### 5.5 详情页与商店页详情

- **报告/周报详情**：展示标题、来源、日期、标签、正文（支持 Markdown）。左上角「返回」回到列表，并保留之前选择的监测源与分类。
- **商店页详情**：当条目为「商店页变化」等类型时，可能跳转到商店页详情，展示该应用/游戏的商店信息与变更摘要。

## 六、周报内容说明（网站端）

### 6.1 微信/抖音小游戏周报

- 来源：与微信、抖音小游戏相关的周报数据（如 `public/休闲游戏检测/` 下配置或数据库中的周报）。
- 在侧栏选「微信/抖音」+「周报简要」或「新游戏」+ 对应平台后，列表中会出现对应周报条目，点击可看全文。

### 6.2 SensorTower 周报

- 来源：`sensortower_top100.db` 中的 `rank_changes` 等表，由系统生成周报条目。
- 内容结构与企业微信推送一致：新进 Top50、排名飙升 Top10、商店页更新等；网站端可查看完整正文与链接。
- 在侧栏选「SensorTower」+「周报简要」即可在列表中看到各期 SensorTower 周报。

### 6.3 竞品社媒周报

- 在「竞品 → 社媒更新」下展示，可按公司筛选。
- 每条为竞品社媒周报摘要或全文，点击卡片进入详情页阅读。

## 七、简要操作速查

| 想做的事                 | 操作 |
|--------------------------|------|
| 看微信/抖音小游戏榜单    | 首页点「微信/抖音小游戏」或侧栏选「微信/抖音」+「新游戏」→ 点「进入排行榜」。 |
| 看 SensorTower 全球榜单  | 首页点「SensorTower 榜单」或侧栏选「SensorTower」→ 进入排行榜页并切换 iOS/Android。 |
| 看本周 SensorTower 周报  | 侧栏选「SensorTower」+「周报简要」→ 在列表中点对应周报卡片。 |
| 看竞品社媒/UA             | 首页点「竞品监测」或侧栏选「竞品」→「社媒更新」或「UA 素材」；社媒可再选公司。 |
| 看商店页变化             | 侧栏选「SensorTower」+「商店页变化」→ 点某条进入商店页详情。 |
| 在企业微信收周报         | 由管理员配置 Webhook 与定时任务；收到 Markdown 消息后点击文末链接可打开网站完整周报。 |
