# 监测助手使用说明（用户视角）

本文档面向**使用本网站的访客与业务同学**，说明右下角 **「AI 对话 / 监测助手」** 能做什么、不能做什么，以及数据与隐私边界。  
（技术部署、接口与运维请参阅站内其他开发文档。）

---

## 一、监测助手是什么

- 监测助手是网站右下角的 **AI 对话浮层**，您可以用**自然语言**提问，例如：解释当前页面数据、询问榜单含义、了解如何在本站找到某类信息。
- 它会结合**您当前浏览的页面**（若适用）与站内可见内容，尽量给出可理解的回答；部分场景下，回答会在**服务端**结合更多数据做核对，但**您本人不会因此获得任何「后台直连数据库」的能力**。

---

## 二、您能做什么（用户侧能力）

| 您可以 | 说明 |
|--------|------|
| 打开各监测列表、详情、排行榜等 **网页** | 所有正式数据都通过这些 **页面与表格** 展示 |
| 使用页内筛选、搜索、导出（若该页已提供） | 以各页面实际按钮为准 |
| 在监测助手中 **用中文提问、多轮追问** | 支持换行（Shift+Enter）、发送前可修改文字 |
| 使用助手提供的 **快捷提问按钮**（若有） | 一键发送常见问法 |
| 在助手中 **切换、重命名、删除对话**（会话列表在浮层一侧） | 对话记录默认保存在 **本机浏览器**（见下文「隐私」） |

---

## 三、您不能做什么（重要边界）

以下能力**不属于**网站向普通用户开放的范围，监测助手也**不会**为您提供：

| 您不能 | 原因 |
|--------|------|
| **直接访问数据库**（如 SQLite、表、执行 SQL） | 数据仅通过 **网站页面** 呈现；库文件在服务端，用户无直连权限 |
| **下载原始数据库文件**（`.db` 等）或「自己查库」 | 同上 |
| 把站内地址当成「调接口」去自行编程调用 | 普通使用只需 **在浏览器里点开页面**；技术对接另有文档与权限 |
| 要求助手「把表结构/内部路径当操作步骤教给我」 | 助手应引导您使用 **页面入口与列表**，而非数据库术语 |

若您听到或看到类似「可以访问 `某某.db`」的说法，请以本文为准：**那是给系统内部参考的，不是用户操作**。

---

## 四、数据从哪里来、您看到的是什么

- 您在页面上看到的排名、周报、列表等，都来自团队在服务端维护的监测与同步流程，**经网站整理后展示**。
- 监测助手在回答时，可能会利用服务端能力做核对，但**输出给您的应是业务语言**（例如「在微信小游戏排行榜第 N 名」），而不是 SQL、表名、文件路径。
- **若页面没有展示某条数据**，助手通常也无法凭空「变出」未在站内发布的内容；请以页面与官方导出为准。

---

## 五、登录与网络

- 若站点配置为 **需登录** 后才能使用 AI，请先完成登录；未登录时助手可能提示无权限。
- 助手依赖网络连接后端服务；网络异常或维护时，可能暂时无法回复。

---

## 六、对话记录与隐私（简要）

- **对话列表与内容**通常保存在您 **本机浏览器** 的本地存储中，**不会**自动同步到您在其他设备上的浏览器。
- 请勿在对话中发送 **密码、密钥、未公开合同** 等敏感信息；团队侧对服务端日志与合规的要求以公司政策为准。

---

## 七、回答里的链接与「路径」

- 有时助手会给出 **可点击的文字链接**，跳转到本站某个页面（例如排行榜、某类监测列表）。
- 这些是 **网站里的页面地址**，方便您少点几次菜单；**不是**让您去「访问数据库」或「调用接口」。
- 若某句话里出现难懂的技术词，您可以直接追问：「请用「要点哪里」再说一遍」。

---

## 八、与《监测汇总网站说明》的关系

- **网站整体怎么用**（导航、列表、排行榜、监测源等）：请优先阅读 **[监测汇总网站说明](./监测汇总网站说明.md)**。
- 本文只补充 **监测助手** 的定位与**数据访问边界**；二者配合使用即可。

---

## 九、反馈与期望

- 若助手 **编造了不存在的按钮或页面**，或 **暗示您可以查库/SQL**，请向维护团队反馈，以便改进提示与知识库。
- 若您需要 **导出数据、API 对接、原始底表**，属于**数据与权限申请**范畴，需走团队正式流程，**不是**通过本对话浮层完成。

---

## 十、休闲游戏飞书 Agent

后端支持一个独立的休闲游戏飞书 Agent，事件订阅地址为：

- `POST /api/feishu/casual-agent/events`

建议在飞书开放平台创建**独立自建应用**，并配置独立的 `CASUAL_FEISHU_APP_ID`、`CASUAL_FEISHU_APP_SECRET`、`CASUAL_FEISHU_VERIFICATION_TOKEN`。开启方式：

```env
CASUAL_FEISHU_BOT_ENABLED=true
CASUAL_FEISHU_BOT_MENTION_NAMES=休闲监测助手,休闲游戏助手
```

能力范围包括微信/抖音小游戏、SensorTower、竞品社媒/UA、我方产品榜单追踪。群聊中需要 @ 配置的机器人名，私聊会直接响应。生产环境建议配置 `CASUAL_FEISHU_ALLOWED_OPEN_IDS` 或 `CASUAL_FEISHU_ALLOWED_CHAT_IDS` 做访问控制。

完整配置步骤见 **[休闲游戏飞书 Agent 配置指南](./休闲游戏飞书Agent配置指南.md)**。
