# 监测数据怎么查看（用户说明）

## 你能做什么

- 在浏览器里打开本站的**监测列表、周报详情、排行榜、表格**等页面，查看已经整理好的内容。
- 若站点配置了**账号登录**，请用管理员提供的账号登录后再浏览；数据请求会经服务器校验。

## 你不能（也不需要）做什么

- **不能**自己打开数据库文件、执行 SQL、或把 `.db` 当普通下载使用。日常分析请**只看网页上的列表与详情**。
- 「Agent / 助手」在后台可能用工具核对数据，那是**服务端能力**，不开放给终端用户直接操作数据库。

## 两种常见部署方式（了解即可）

- **静态页面**：部分数据随页面一起发布，访问方式由部署地址决定。
- **带后端的站点**：登录后，前端通过安全接口拉取 `public` 目录下的数据文件并在页面上展示；你仍只需使用网页界面，无需关心文件路径。

## 数据更新

- 各类报表、榜单的更新节奏以团队内部流程为准；页面上看到的时间、日期即为当前展示口径。
