# 监测汇总网站说明

本文档介绍**监测汇总平台**网站的功能与界面，帮助您快速了解网站能做什么、页面上有哪些内容、以及如何使用。

> **与代码同步**：界面以仓库当前前端为准；顶栏无全局搜索框、通知铃铛、夜间模式开关；休闲游戏默认展示 **SensorTower** 数据块，侧栏中 **SensorTower 榜单** 在 **微信 / 抖音小游戏** 之上。

---

## 一、网站是做什么的

监测汇总平台把多类监测内容集中在一个网站里展示，包括：

- **AI 热点**：AI 领域的新动态、技术突破、行业热点
- **热点趋势**：全网话题热度、讨论量、趋势变化
- **AI 产品**：产品周报、UA 素材、素材库榜单等
- **休闲游戏**：微信/抖音小游戏与 SensorTower 榜单相关周报、商店页变化、新游戏、竞品社媒与 UA 素材等

您可以通过**首页**或**顶部导航**进入各类型，在中间主区域浏览列表、点进某条看详情，或在休闲游戏下进入排行榜查看各平台游戏排名。

---

## 二、主要功能

### 1. 顶部导航（五种入口）

打开网站后，顶栏提供（具体文案以页面为准）：

| 入口 | 作用 |
|------|------|
| **监测汇总**（或「全部」） | 回到首页 `/`，展示汇总与四类入口卡片 |
| **AI热点** | 进入 `/type/ai热点监测`（URL 中为编码后的中文类型名） |
| **趋势监测** | 进入 `/type/热点趋势监测` |
| **休闲游戏监测** | 直接进入 `/type/休闲游戏监测` 工作台（**不再经过**单独的模块引导页） |
| **AI产品监测** | 进入 `/type/AI产品监测` |

点击任一类型后，中间列表与右侧「监测源」会一起切换。

### 2. 休闲游戏下的细分

选择「休闲游戏监测」后，右侧「监测源」会出现两大**数据块**（自上而下）：

1. **SensorTower 榜单**（默认进入时选中该块）  
   - 子项包括：**周报简要**、**商店页变化**（仅本块下有「商店页变化」）。
2. **微信 / 抖音小游戏**  
   - 子项包括：**周报简要** 等（与微信/抖音来源数据对应）。

另有 **竞品监测**（社媒监控、UA 素材）、**我方产品检测**。我方产品检测包含：

- **US 免费榜日总结**：从我方产品 US 免费榜库读取日环比摘要，卡片可进入详情查看上升/下降明细。
- **按产品追溯**：左侧只列我方产品；选择产品后可用下拉框切换该产品对应竞品，查看 iPhone / iPad / Android 各分类榜的排名曲线。

主区域上方在休闲游戏场景下可提供快捷卡片：**微信/抖音排行榜**、**SensorTower 排行榜**、**竞品监测** 等入口按钮；工作台内也可进入 `/rankings/casual/wechat_douyin` 或 `/rankings/casual/sensortower` 等排行榜页。

### 3. 列表的筛选和排序

主区域上方有筛选与排序（随类型变化）：

- **时间范围**：过去 1 周、1 个月、3 个月，或全部时间。
- **分类 / 平台**：随右侧「监测源」所选类型、数据源块、子类变化。
- **排序**：默认排序、最新发布、最受欢迎等（以页面可选项为准）。

列表上方会显示找到的数据条数。部分视图下会简化筛选栏（例如仅按日期等）。

### 4. 查看详情

列表里每条监测以卡片形式展示。**有完整内容的条目**（如周报）可点击整张卡片，进入**详情页**阅读全文。

详情页会显示标题、来源、日期、正文等。提供**返回**逻辑：会尽量回到进入前的列表与侧栏状态（含休闲游戏数据源块等）。

### 5. 休闲游戏排行榜

从休闲游戏工作台或相关按钮进入排行榜子路由，例如：

- `/rankings/casual/wechat_douyin`：微信 / 抖音小游戏榜相关视图  
- `/rankings/casual/sensortower`：SensorTower Top100 等  

页面内提供**返回**，可回到上一页并带上合适的 `returnTo` 状态。

### 6. 登录与账户

若部署了后端并启用登录，顶栏会显示当前用户名与 **退出**。未登录且需要鉴权的功能以实际环境为准。

## 三、页面上有哪些内容（界面说明）

### 1. 整体布局

- **最上方**：固定顶栏（Logo、类型导航、用户区）。
- **中间偏左**：主内容区——列表、详情或排行榜等。
- **右侧**：固定宽度侧栏「**监测源**」，内容过多时**侧栏内部**可纵向滚动。

### 2. 顶部导航栏

- **左侧**：Logo 与站点名称「监测汇总」。
- **中间**：类型按钮；当前选中项为**深色块 + 硬边阴影**风格（非旧版圆角蓝底药丸）。
- **右侧**：登录用户显示用户名与退出；未登录时显示「未登录」等提示。

### 3. 首页 `/`

- 大标题与实时统计摘要（监测类型数、条目数、周报数、AI 素材相关数量等）。
- 四张入口卡片对应四类监测，点击进入对应 `/type/...` 工作台。

### 4. 主内容区常见画面

**（1）列表页**  
标题区含面包屑式路径（休闲游戏下与侧栏一致）与主标题；部分类型在标题旁有快捷操作（如进入素材库、进入排行榜）。

**（2）监测卡片**  
展示标题、来源、时间、标签等；可点击的条目进入详情。

**（3）详情页**  
报告/商店页等详情布局，带返回。

**（4）排行榜页**  
表格或分平台视图，具体列以页面为准。

### 5. 右侧「监测源」边栏

- 标题：**监测源**。
- **全部**（若展示）：查看跨类型汇总（与首页入口一致时以路由为准）。
- **按类型**：AI 热点、热点趋势、休闲游戏、AI 产品等；展开休闲游戏时出现上文「二、2」中的结构。

### 6. 视觉与体验（当前版本）

- **风格**：浅灰底 + 细网格感背景、高对比文字、**粗边框与硬阴影**（新粗野主义/终端面板取向），非旧版大圆角柔和风。
- **字体**：中文与界面文案以中文为主；标题数字可用展示字体强化层次。
- **响应式**：窄屏下仍为左右分栏思路为主（主内容 + 侧栏），请以实际浏览器宽度为准。

## 四、独立休闲入口 `casual.html`

构建后除 `index.html` 外还有 **`casual.html`**，加载独立 bundle，仅包含休闲游戏相关页面（见 `src/casual/`）。适合只需休闲游戏能力、或嵌入第三方页面的场景。详见 **[休闲游戏监测周报.md](./休闲游戏监测周报.md)** 等文档。

## 五、监测助手（AI 对话）

网站右下角提供 **「AI 对话」**（监测助手），可用自然语言提问。

- 您**不能**通过助手在浏览器里「直接执行 SQL」访问数据库；数据以**各页面列表、详情、排行榜**为准。
- 更完整的说明见：**[监测助手使用说明](./监测助手使用说明.md)**。

## 七、简要总结

| 项目 | 说明 |
|------|------|
| **网站用途** | 集中展示 AI 热点、热点趋势、AI 产品、休闲游戏等多类监测；支持筛选、排序、详情与排行榜。 |
| **路由习惯** | 首页 `/`；类型工作台 `/type/:监测类型`；休闲游戏排行榜 `/rankings/casual/:section` 等。 |
| **休闲游戏默认** | 默认数据源块为 **SensorTower**；侧栏 **SensorTower** 在 **微信/抖音** 之上。 |
| **界面文案** | 以中文为主；顶栏无全局搜索/通知/夜间模式（以当前代码为准）。 |
| **监测助手** | 见「五、监测助手」与 **[监测助手使用说明](./监测助手使用说明.md)**。 |
