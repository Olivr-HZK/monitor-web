# 监测链定时任务规范

本文只约束 `monitor-web` 监测链：微信/抖音小游戏、SensorTower、竞品社媒，以及它们进入后端和推送的链路。其它日报或外部项目可以通过统一 runner 托管，但不作为四库推送的阻断依赖。

## 核心原则

监测链固定按下面顺序执行：

```text
爬取/入库 -> 镜像数据库 -> 检查后端连接与 /api/data 快照 -> 推送
```

任何一个阻断检查失败，都不应继续推送。临时救急需要显式开关，例如 `SYNC_ALLOW_STALE_SOURCES=1`，并人工确认数据。

## 项目边界

| 内容 | 标准位置 |
|------|----------|
| 调度入口 | `scripts/cron/run_job.sh` |
| 监测链源码 | `pipelines/monitor-chain/` |
| canonical 数据库 | `data/databases/` |
| 统一日志 | `logs/jobs/` |
| 集中校验与推送 | `scripts/sync_dbs_and_deploy.sh` |
| 只检查不推送 | `scripts/check_monitor_chain.sh` |

四份 canonical 数据库：

| 数据库 | 来源 pipeline |
|--------|---------------|
| `wechatdouyin.db` | `pipelines/monitor-chain/wechat-douyin/` |
| `sensortower_top100.db` | `pipelines/monitor-chain/sensortower/` |
| `us_free_appid_weekly.db` | `pipelines/monitor-chain/sensortower/` |
| `competitor_data.db` | `pipelines/monitor-chain/competitor-social/` |

`data/databases/` 被 git 忽略，只保存本机运行数据，不进入版本库。

## 调度标准

首选统一 crontab block：

```text
scripts/cron/monitor-web-unified.cron.fragment.txt
```

每个任务应通过 job id 运行：

```bash
./scripts/cron/run_job.sh sensortower_weekly
```

直接路径版 `scripts/monitoring-chain.cron.fragment.txt` 仅作为迁移期参考。新增或长期任务应进入 `scripts/cron/run_job.sh`。

## 周一时间阶梯

| 时间 | 环节 |
|------|------|
| 7:30 | 微信/抖音三榜、SensorTower 周工作流、竞品日爬 |
| 7:40 | 竞品周报工作流 |
| 8:30 | SensorTower US 免费榜日更 |
| 8:45 | monitor-web 校验四库、检查后端 `/api/data`、通过后推送 |
| 8:50 / 9:50 | 微信/抖音完整性补跑 |

`sync_dbs_and_deploy.sh` 默认 `SYNC_CUTOFF_HOUR=7`，用于判断源库是否足够新。调整执行时间时要同步评估 cutoff。

## 运行与依赖

| 项 | 要求 |
|----|------|
| Python/Node PATH | 由 `scripts/cron/run_job.sh` 统一补齐 |
| Python pipeline 依赖 | 各 pipeline 优先使用自己的 `.venv`，例如 `pipelines/monitor-chain/competitor-social/.venv` |
| 机密 | 放在本项目 `.env`、pipeline 本地 `.env` 或系统环境变量，不写入仓库 |
| 数据镜像 | 使用 `scripts/db/mirror_databases.py`，避免直接拷贝正在写入的 SQLite/WAL 文件 |
| 后端连接检查 | 必须检查 `/api/data/*.db` 返回的 SQLite 快照可读 |

## 过渡状态

本机曾遇到 macOS `crontab` 写入卡住，因此 SensorTower 和竞品社媒的系统 crontab 可能仍显示旧仓库路径。对应旧 wrapper 已改成先转发到：

```text
monitor-web/scripts/cron/run_job.sh
```

这只是生产不中断的过渡方案。稳定运行一轮后，应再次执行：

```bash
./scripts/cron/install_unified_cron.sh --apply --replace-known
```

然后删除旧 wrapper 转发。若 `crontab` 写入仍卡住，先保留旧 wrapper；此时它们已经通过统一 runner 获得 `logs/jobs/<job-id>.log`、锁和 last_status。

## 推送约定

周一集中链路默认只推送：

- SensorTower 周报
- 竞品社媒周报
- 微信/抖音小游戏周报

watchdog / 健康检查只发飞书状态摘要，不再发企业微信。状态内容应突出阻断项、日期、关键记录数和日志路径，避免长篇输出影响诊断。
