# monitor-web 监测链定时调度

本文说明当前整合方式：只把 monitor-web 相关的监测链入口收口到 `monitor-web/scripts/cron/run_job.sh` 与 `pipelines/monitor-chain/`，并把四份核心数据库统一写入或镜像到 `monitor-web/data/databases/`。统一入口负责补齐 PATH、加锁、记录日志和输出最后状态；其它本机项目继续由各自项目的 cron 入口负责。

## 目录与文件

| 文件 | 作用 |
|------|------|
| `scripts/cron/run_job.sh` | monitor-web job runner，按 job id 调用监测链脚本 |
| `scripts/cron/monitor-web-unified.cron.fragment.txt` | 统一 crontab 片段模板 |
| `scripts/cron/install_unified_cron.sh` | 预览/安装统一 crontab，可移除已知旧 cron 行 |
| `scripts/db/mirror_databases.py` | 用 SQLite backup API 把上游四库镜像到 `data/databases/` |
| `data/databases/*.db` | monitor-web 内 canonical 数据库快照（被 git 忽略） |
| `logs/jobs/<job-id>.log` | 每个 job 的统一日志 |
| `logs/jobs/<job-id>.last_status` | 每个 job 最近一次状态 |
| `logs/jobs/locks/<job-id>.lock` | 防止同一 job 重叠运行的锁目录 |

## 使用方式

查看所有可用 job：

```bash
./scripts/cron/run_job.sh --help
```

预览某个 job 会执行什么，不真正运行：

```bash
JOB_DRY_RUN=1 ./scripts/cron/run_job.sh sensortower_weekly
```

`JOB_DRY_RUN=1` 只打印将要执行的命令，不写入 `logs/jobs/<job-id>.last_status`。

预览统一 crontab 完整内容，不写入系统：

```bash
./scripts/cron/install_unified_cron.sh
```

只打印统一 block：

```bash
./scripts/cron/install_unified_cron.sh --print-block
```

安装统一 block，并移除当前 crontab 中 monitor-web 监测链相关的旧入口，避免重复运行：

```bash
./scripts/cron/install_unified_cron.sh --apply --replace-known
```

安装脚本会先备份当前 crontab 到：

```text
logs/cron-backups/crontab-before-unified-YYYYMMDD-HHMMSS.txt
```

并保存候选 crontab 到：

```text
logs/cron-backups/crontab-unified-next-YYYYMMDD-HHMMSS.txt
```

如果 macOS `crontab` 写入卡住，安装脚本会按 `CRONTAB_INSTALL_TIMEOUT`（默认 20 秒）超时退出，不会留下悬挂的 `crontab` 进程。此时先保留旧 cron wrapper 转发；SensorTower、微信/抖音和竞品社媒的旧 wrapper 已进入 `scripts/cron/run_job.sh`，待系统 crontab 恢复后再安装候选文件。

当前本机已安装统一 cron block。若需要重装或修复 crontab，执行：

```bash
cd /Users/ggbond/lyb/monitor-web
./scripts/cron/install_unified_cron.sh --apply --replace-known
```

## 路径约定

默认按当前机器路径推断：

| 变量 | 默认值 |
|------|--------|
| `LYB_ROOT` | `monitor-web` 的上一级，也就是 `/Users/ggbond/lyb` |
| `WORKSPACE_ROOT` | `$HOME/workspace` |
| `OLIVER_ROOT` | `$HOME/oliver` |
| `OPENCLAW_WORKSPACE` | `$HOME/.openclaw/workspace` |
| `MONITOR_WEB_JOB_LOG_DIR` | `monitor-web/logs/jobs` |
| `MONITOR_LOCAL_DB_DIR` | `monitor-web/data/databases` |

换机器时可在 crontab 或 shell 环境里覆盖这些变量。
