# 自动任务与推送

## 每日 10:30：热点日报 + AI 日报

每天上午 10:30 自动将**最新热点日报**和 **AI 日报**推送到飞书、企业微信。

### 1. 执行脚本

```bash
# 发送当天热点 + AI 日报（会自动激活 .venv）
./scripts/run_daily_digest.sh

# 发送指定日期的日报
./scripts/run_daily_digest.sh --date 2026-02-10
```

脚本内部执行：`python3 scripts/send_minigame_weekly_reports.py --content hot,ai`；加 `--date YYYY-MM-DD` 会加载该日期的热点 JSON（如 `public/热点/2026-02-10.json`）和 AI JSON（如 `public/ai热点/2026-02-10.json`）。

### 2. 配置 Crontab

在服务器或本机配置定时任务（请将路径改为你的项目绝对路径）：

```bash
crontab -e
```

添加一行（示例路径请替换为实际路径）：

```cron
# 每天 10:30 发送热点日报 + AI 日报（路径示例：本仓库在 ~/lyb/monitor-web）
30 10 * * * /Users/ggbond/lyb/monitor-web/scripts/run_daily_digest.sh >> /Users/ggbond/lyb/monitor-web/logs/daily_digest.log 2>&1
```

如需先创建日志目录：

```bash
mkdir -p /Users/ggbond/lyb/monitor-web/logs
```

### 3. 环境变量

确保项目根目录 `.env` 中已配置：

- `FEISHU_WEBHOOK_URL`：飞书机器人 Webhook
- `WECOM_WEBHOOK_URL_REAL` 或 `WECOM_WEBHOOK_URL`：企业微信机器人 Webhook

### 4. 热点 / AI 数据文件（按日期）

- **热点**：从 `public/热点/` 按日期选 JSON。使用 `--date 2026-02-10` 或当天时，查找顺序：`2026-02-10.json` → `final_json_from_csv_20260210.json` → `final_json_from_csv.json`。
- **AI 日报**：从 `public/ai热点/` 按日期选 JSON。查找顺序：`2026-02-10.json` → `report_documents_with_images.json` → `final_result.json`，都没有则用 `日报.md`。

不传 `--date` 时使用当天日期。指定日期示例：`./scripts/run_daily_digest.sh --date 2026-02-10`。

### 5. 竞品检测简报（玩法更新 / 线下活动）

从 `competitor_data.db` 的 `weekly_reports` 中筛选**含「玩法更新」或「线下活动」**且能解析出**可用性评分**的周报，按评分从高到低推送一条简报（飞书 + 企业微信）。

```bash
python3 scripts/send_competitor_digest.py                     # 最新一周
python3 scripts/send_competitor_digest.py --date 2026-02-16   # 指定该周（start_date）
python3 scripts/send_competitor_digest.py --db public/competitor_data.db --dry-run  # 仅预览
```

可与定时任务配合（如每周一 10:30 在游戏周报之后执行）。

### 6. 其它推送

- **一键三条核心周报**（SensorTower / 竞品社媒 / 微信抖音，与 `sync_dbs_and_deploy.sh` 成功后的推送顺序一致）：  
  `./scripts/run_all_latest_reports.sh`
- **游戏检测周报**（每周一 10:30）：可单独配置一条 cron，执行  
  `./scripts/run_reports.sh --content game`
- **手动发送**：  
  `./scripts/run_reports.sh --content hot,ai`  
  `./scripts/run_reports.sh --content game,hot,ai --dry-run`（仅预览）
